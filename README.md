# HEIZKING

Heizöl-Preisvergleich für Deutschland mit internem Verwaltungsbereich für Bestellungen, Brandings, Bankkonten, Rechnungen und Benachrichtigungen.

## Entwicklung

```sh
bun install
bun run dev
```

Die Anwendung läuft danach unter `http://localhost:8080`.

## Technik

- TanStack Start (React 19, Vite)
- Tailwind CSS
- Supabase (Datenbank, Auth, Storage)
